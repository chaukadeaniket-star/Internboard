/*{STUDENT PROFILE DATA}*/
Registration creates a student profile object with:
- name: the student's full name
- email: the student's email address
- internId: a generated InternBoard identifier

/*{STORAGE}*/
The profile is saved in sessionStorage under the key internboard.studentProfile.
The password is never included in this profile object.
Session storage is local to the current browser tab/session and is not an account database.

/*{DASHBOARD DISPLAY}*/
pages/student-dashboard.html reads the saved profile to show the student's name, email, Intern ID, and initials.
If browser storage is unavailable, the dashboard displays an explanatory message and falls back to sample profile details.

/*{APPLICATION PROFILE PREFILL}*/
pages/apply.html uses the saved name and email to prefill the application form when available.
Application records themselves are saved separately in localStorage under internboard.applications.

/*{DEMO LIMITATIONS}*/
The profile is not sent to a server and is not shared across browsers or devices.
